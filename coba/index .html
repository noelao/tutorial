Quick Start

Panduan singkat untuk menjalankan project pertama menggunakan Express dan EJS dalam hitungan menit. Tidak perlu konfigurasi rumit.

Prerequisites

Pastikan kamu sudah menginstall Node.js versi 18 atau lebih baru. Cek versinya dengan perintah berikut:

bash
node --version

Install dependencies

Info
Gunakan npm, yarn, atau pnpm — semua kompatibel.
bash
# init project npm init -y npm install express ejs

Setup server

Buat file index.js di root project kamu, lalu isi dengan kode berikut:

javascript
const express = require('express') const path = require('path') const app = express() app.set('view engine', 'ejs') app.set('views', path.join(__dirname, 'views')) app.use(express.static('public')) app.get('/', (req, res) => { res.render('index', { title: 'Home' }) }) app.listen(3000, () => { console.log('Server running on http://localhost:3000') })

Struktur folder

Susun folder project kamu seperti ini agar Express bisa menemukan view dan static files dengan benar:

text
project/ ├── views/ │ ├── layout/ │ │ └── base.ejs │ └── index.ejs ├── public/ │ └── css/ │ └── style.css ├── index.js └── package.json

res.render() options

Parameter yang tersedia saat memanggil res.render():

Parameter Type Keterangan
view string Nama file EJS tanpa ekstensi. Dicari di folder views/.
locals object Data yang dikirim ke template. Dapat diakses langsung di EJS.
callback function Opsional. Dipanggil setelah render selesai dengan (err, html).
Perhatian
Jika view engine belum di-set, kamu harus menyertakan ekstensi file secara eksplisit, misalnya res.render('index.ejs').

Jalankan server

bash
node index.js
Berhasil
Buka browser dan akses http://localhost:3000 — server sudah berjalan.
